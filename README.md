# Farmakode 💊 — Visual-First OTC Medicine Safety Platform

> **"Know What You’re Taking."**  
> Instant duplicate active ingredient collision detection and safety verification for over-the-counter medicines.

---

## 🌐 Overview

Farmakode is a minimal, visual-first platform engineered to prevent unintended drug overdoses and duplicate active ingredient collisions across OTC medications.

### Key Features
- **Visual Duplicate Collision Detection**: Side-by-side active ingredient analysis highlighting overlapping compounds (e.g. Paracetamol + Multi-Symptom Night Flu).
- **Three-Step Workflow**: 📷 *Scan* → 🧬 *Identify* → ⚠️ *Check*.
- **Interactive Live Simulator**: Real-time OTC collision engine with synthesized auditory and visual alerts.
- **Apple-like Minimalist Healthcare Aesthetic**: Soft lavender canvas, pristine rounded cards, dark typography, and fluid micro-animations.
- **Zero-Dependency Architecture**: Built with pure semantic HTML5, modern CSS3, and lightweight Vanilla JavaScript.
- **Vercel Ready**: Pre-configured with `vercel.json` for instant static edge deployment.

Open `http://localhost:8080` in your web browser.
